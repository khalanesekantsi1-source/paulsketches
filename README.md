# Paul Sketches

Paul Sketches is a Lesotho art network for artists and viewers.

## Website address

After GitHub Pages is enabled for this repository, open:

https://khalanesekantsi1-source.github.io/paulsketches/

The included GitHub Actions workflow deploys the site automatically whenever changes are pushed to `main`.

## Why it was not showing on a phone

The previous link was a local `file:///` path. That path points to a file on one computer only; it is not public, searchable, or available to a phone. Google can only index a site hosted at a public web address.

To make the site searchable for “Paul Sketches”:

1. Push the repository to GitHub.
2. In the repository, open **Settings → Pages**.
3. Set the source to **GitHub Actions** and save.
4. Open the Pages address above from your phone.
5. Submit that URL to Google Search Console. Indexing can take days or weeks.
